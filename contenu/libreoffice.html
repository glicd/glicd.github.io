LibreOffice, une suite bureautique complète : LibreOffice

LibreOffice est une suite bureautique complète Libre & Open Source. Elle est installée par défaut sur toutes les versions actuelles de Debian. Debian/LibreOffice

Le site officiel LibreOffice

Qu'est-ce que LibreOffice : ici

Documentation LibreOffice : Doc

Et le Wiki.documentfoundation

  • Ouvrir la suite bureautique LibreOffice
    Simple clic > Applications > Bureautique > LibreOffice ...

    • LibreOffice Calc est un tableur : Découvrir Calc
      Si besoin, le guide utilisateur officiel.

    • LibreOffice Draw permet de créer des dessins simples ou complexes et plus encore : Découvrir Draw
      Si besoin, le guide utilisateur officiel.

      Pour information, il est aussi possible d'ouvrir l'application « LibreOffice Draw » dans :
      Applications > Graphisme

    • LibreOffice Impress permet de créer des présentations multimédia : Découvrir Impress
      Si besoin, le guide utilisateur officiel.

    • LibreOffice Math est l'éditeur de formules mathématiques et scientifiques : Découvrir Math
      Si besoin, le guide utilisateur officiel.

    • LibreOffice Start Center (Centre de Démarrage) permet de lancer toutes les applications de LibreOffice

    • LibreOffice Writer a les fonctionnalitées d'un outil d'édition bureautique et d'un traitement de texte : Découvrir Writer
      Si besoin, le guide utilisateur officiel.

  • Connaître la version de LibreOffice, pour consulter le guide utilisateur correspondant :
    Simple clic > Aide (dans n'importe quelle application de LibreOffice ouverte)

    • Un menu déroulant apparaît:
      Simple clic > A propos de LibreOffice

    • La fenêtre « A propos de LibreOffice » s'ouvre.

    • Sous « Information de version » le version de LibreOffice avec divers renseignements
      Il est possible d'accéder directement au site de LibreOffice : Simple clic > Site web
    • Fermer la fenêtre : Simple clic > Fermer
      Fermer LibreOffice : Simple clic > Fichier > Quitter LibreOffice
