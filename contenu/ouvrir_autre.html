Ouvrir avec une autre application : Le site Xfce.

Sur Debian avec le bureau Xfce, les applications sont définies automatiquement en fonction du fichier à ouvrir.

L'application définie automatiquement peut ne pas convenir, il est possible d'ouvrir un fichier avec une autre application ou de définir une application par défaut (son application préférée).
Si besoin se rendre au chapitre « Gestionnaire de fichiers avec Thunar : Définir l'application par défaut par l'utilisateur »

Exemple : Ouvrir le fichier « chanson.mp3 » qui se trouve dans le dossier Musique avec une autre application que celle définie automatiquement.
L'application définie automatiquement est « Parole », l'application choisie sera « Quod Libet »

  • Ouvrir le gestionnaire de fichiers : Simple clic > Applications > Gestionnaire de fichiers

  • Le gestionnaire de fichiers Thunar s'ouvre.
    Ici, debian (nom utilisateur) doit être en bleu.

  • Double clic > Musique

  • Clic droit sur le fichier à ouvrir « chanson.mp3 », un menu déroulant apparaît.

  • Positionner le pointeur de la souris sur « Ouvrir avec »

  • Un menu déroulant apparaît avec des propositions.
    Le fichier à ouvrir est un fichier de musique « chanson.mp3 »
    Donc seules les applications de musiques sont proposées. Dans cet exemple « Quod Libet »
    Cette application est disponible sur le PC.
    Si une autre application de musique était disponible, elle se retrouverait dans cette liste.
    Simple clic > Quod Libet

  • L'application « Quod Libet » s'ouvre et se lance.

  • Le site de Quod Libet
  • Quitter l'application « Quod Libet »
    Simple clic > Fichier > Quitter

Nota : Si aucune application n'a été définie par défaut par l'utilisateur, c'est maintenant l'application
« Quod Libet » qui sera l'application prioritaire pour ouvrir des fichiers musicaux.
Si besoin se rendre au chapitre « Gestionnaire de fichiers avec Thunar : Définir l'application par défaut par l'utilisateur »

La procédure reste la même pour ouvrir n'importe quel fichier avec une autre application.
Cela va de soit, mais le type d'application doit être compatible avec le type de fichier à ouvrir.
