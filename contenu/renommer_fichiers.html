Renommer un dossier ou un fichier : Le site Xfce.

Exemple : Renommer le fichier « chanson.mp3 » qui se trouve dans le dossier Musique.
Utiliser la même procédure pour renommer un dossier.

  • Ouvrir le gestionnaire de fichiers : Simple clic > Applications > Gestionnaire de fichiers

  • Le gestionnaire de fichiers Thunar s'ouvre.
    Ici, debian (nom utilisateur) doit être en bleu.

  • Double clic > Musique

  • Clic droit sur le fichier à renommer « chanson.mp3 », une fenêtre apparaît.

  • Simple clic > Renommer

  • Une fenêtre apparaît.
    Remarque : Seul le mot « chanson » est souligné en bleu et le curseur est avant le « .mp3 ».
    ATTENTION : ne pas renommer ou supprimer le « .mp3 (point mp3) » car il s'agit du type de fichier.

  • Saisir avec le clavier le nom du nouveau fichier, ici « MEMO.mp3 »
    Puis simple clic > Renommer

  • Le fichier « chanson.mp3 » a été renommé en « MEMO.mp3 » dans le dossier Musique.
    Nota : A la place de l'icône note de musique, il peut y avoir la pochette de l'album.

  • Fermer le gestionnaire de fichiers : Simple clic > Fichier > Fermer la fenêtre
