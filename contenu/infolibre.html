Le logiciel libre :

Le « Logiciel Libre » ou « Free Software » ou bien « Libre Software » ne veut pas dire logiciel gratuit.

  • c'est un logiciel qui respecte la liberté des utilisateurs. Projet GNU
  • les utilisateurs ont la liberté d'exécuter, copier, distribuer, étudier, modifier et améliorer ce logiciel.

Pour plus d'info sur le logiciel libre et son histoire, se rendre sur wikipedia : Logiciel_Libre

Nota :Un logiciel « Open source » n'est pas un « Logiciel Libre ».

Les principes du logiciel libre selon Debian :

Les principes du logiciel libre selon Debian sont rédigés sur la page le contrat social de Debian.

Pour que le système d'exploitation Debian reste entièrement libre, il faut mettre dans le fichier
sources.list, « main » et seulement « main ». h-node.org

Remarque :
Dans de nombreux cas pour utiliser Debian, il est nécessaire d'installer des paquets qui ne font pas partie
du système Debian.
Ces paquets se trouvent dans des sections nommées « contrib » (contributions), « non-free » (non libre) et
non-free-firmware (microprogramme non libre). DebianBookworm

Il est donc souhaitable de lire les licences de ces paquets afin de déterminer s'il est possible de distribuer
Debian avec ces paquets. contrat social

GNU/Linux plutôt que Linux :

Linux est un noyau et les expressions « distribution Linux » ou « système Linux » sont incorrectes.
Ces expressions ne mentionnent pas les logiciels qui complètent toujours ce noyau.
Parmi les logiciels qui complète le noyau Linux, il y a les programmes développés par le projet GNU.
Donc :
Lorsque le système d'exploitation libre GNU a pour noyau Linux, l'appelation est GNU/Linux.

Remarque :
Le noyau Linux ne fonctionne pas seulement avec le système d'exploitation libre GNU et vice versa.

En ce qui concerne Debian, Debian est un système d'exploitation libre.
Pour fonctionner, il a besoin :

  • Du noyau Linux
  • Et d'un ensemble d'utilitaires dont la plupart ont été développés par le projet GNU.

Debian a choisi de nommer GNU et Linux. C'est pourquoi les versions s'appellent Debian GNU/Linux.

Pour aller un peu plus loing, en ajoutant un environnement de bureau libre tel que Xfce
L'appellation peut devenir : Debian GNU/Linux/Xfce ou Debian GNU/Linux avec le bureau Xfce.

Pour plus d'info : debian-handbook.info et wikipedia/linux.
