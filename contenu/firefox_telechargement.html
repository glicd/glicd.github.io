Suivre le téléchargement d'un fichier dans Firefox : Le site Mozilla / Firefox

Le navigateur Firefox est installé par défaut sur Debian avec le bureau Xfce
La version installée est la version : Firefox ESR (Extended Support Release), plus d'information ici.

Qu'est ce qu'un navigateur web?

Avant de se rendre sur internet, il est préférable de configurer un pare-feu.
Si besoin, se rendre au chapitre : Les Applications > Le pare-feu avec l'interface utilisateur graphique gufw

  • Ouvrir le navigateur Firefox
    Simple clic > Applications > Internet > Firefox ESR

  • Le navigateur Firefox s'ouvre

  • Suivre un téléchargement : Exemple téléchargement du fichier Debian
    Simple clic > Téléchargement

  • L'icône d'un cercle et une notification apparaissent
    Le cercle se remplit de bleu au fur et à mesure de l'avancée du téléchargement

  • Suivre l'avancement du téléchargement
    Positionner le pointeur de la souris sur l'icône (le cercle) puis simple clic

  • La notification sur l'avancement du téléchargement apparaît
    La barre se remplit de bleu en fonction de l'avancement du téléchargement
    Le temps restant : 15 minutes, cela dépend de la vitesse de la connexion du réseau.
    La taille du fichier téléchargée : 118 sur 629 Mo (629 Mo est la taille totale du fichier)

  • A la fin du téléchargement le cercle est devenu une flèche
    Le fichier téléchargé se trouve par défaut dans le dossier « Téléchargements ».
    Pour le trouver, ouvrir le gestionnaire de fichiers Thunar. ici

  • Simple clic sur ce bouton (flèche), la notification apparaît :
    Le nom du fichier : debian-12.5.0-amd64-netinst.iso
    Téléchargement terminé avec la taille totale du fichier 629 Mo

  • Quitter Firefox
    Simple clic > Petite croix

  • Par défaut le fichier téléchargé se trouvera dans le dossier Téléchargements

Pour plus d'informations sur trouver et gérer les fichiers téléchargés dans Firefox
