Débrancher le smartphone en toute sécurité : Debian et Xfce

Dans cet exemple, Android est le système d'exploitation du smartphone.

  • Ouvrir le gestionnaire de fichiers : Simple clic > Applications > Gestionnaire de fichiers

  • Le gestionnaire de fichiers Thunar s'ouvre.
    Dans le volet latéral gauche sous « Périphériques » apparaît le smartphone
    sous le nom : MEMOsmart (ce ne sera pas le même nom)

  • Clic droit > smartphone « MEMOsmart »

  • Une liste déroulante apparaît
    Simple clic > Démonter

  • Une notification apparaît en haut à droite de l'écran
    « Démontage du périphérique
    Le périphérique MEMOsmart est en cours de démontage par le système. Veuillez ne pas retirer le support ou déconnecter le lecteur »

  • L'icône représentant le smartphone a dû s'assombrir.
    Attendre que la notification disparaisse.
    Puis, débrancher le smartphone.
  • Après avoir débranché le smartphone, l'icône représentant le smartphone sous « Périphériques » doit disparaître.

  • Fermer le gestionnaire de fichiers : Simple clic > Fichier > Fermer la fenêtre
