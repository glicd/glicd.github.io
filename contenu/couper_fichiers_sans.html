Couper un dossier ou un fichier sans les raccourcis clavier : Le site Xfce.

Couper un fichier ou un dossier le déplace du dossier original.

Exemple : Couper le fichier « chanson.mp3 » qui se trouve dans le dossier Musique vers le dossier Public.

  • Ouvrir le gestionnaire de fichiers : Simple clic > Applications > Gestionnaire de fichiers

  • Le gestionnaire de fichiers Thunar s'ouvre.
    Ici, debian (nom utilisateur) doit être en bleu.

  • Double clic > Musique

  • Clic droit sur le fichier à couper « chanson.mp3 », un menu déroulant apparaît.

  • Simple clic > Couper

  • Le menu déroulant disparaît, le fichier « chanson.mp3 » est surligné en bleu.
    L'icône note de musique est d'une couleur plus claire.

  • Simple clic > debian (l'utilisateur)

  • Double clic > Public

  • Positionner le pointeur de la souris dans la zone principale.

  • Clic droit, un menu déroulant apparaît.

  • Simple clic > coller

  • Le fichier « chanson.mp3 » a été déplacé dans le dossier Public.

  • Pour vérifier : Le fichier « chanson.mp3 » n'est plus dans le dossier Musique
    Simple clic > debian (l'utilisateur)
    Double clic > Musique

  • Fermer le gestionnaire de fichiers : Simple clic > Fichier > Fermer la fenêtre

L'autre solution, voir le chapitre : Couper avec les raccourcis clavier
