Se déplacer dans le gestionnaire de fichiers Thunar

  • Ouvrir le gestionnaire de fichiers : Simple clic > Applications > Gestionnaire de fichiers

  • Le gestionnaire de fichiers Thunar s'ouvre.

  • Pour se déplacer dans le volet latéral, indiqué « 3 », simple clic > Bureau ou Corbeille...

  • Pour se déplacer dans la zone principale, indiqué « 4 », double clic > Documents ou Images...

  • Dans le selecteur d'emplacement, indiqué « 2 », se déplacer à l'aide des flèches est possible.

    • Exemple, se déplacer dans le dossier Musique sous « debian » (l'utilisateur) :
      Double clic > Musique

    • Double clic > Disco

    • Double clic > Année_1970

    • Le fichier « chanson.mp3 » se trouve sous : debian/Musique/Disco/Année_1970

    • A l'aide des 4 icônes encadrées en rouge, il est possible de se déplacer dans les dossiers.

    • Simple clic sur la flèche « aller au dossier visité précédent »

    • Le dossier précédent visité s'ouvre, dans cet exemple : Disco

    • Simple clic sur la flèche « aller au dossier visité suivant »
      La flèche ne doit pas être grisée.

    • Le dossier suivant visité s'ouvre, dans cet exemple : Année_1970

    • Simple clic sur la flèche « ouvrir le dossier parent »

    • Le dossier parent s'ouvre, dans cet exemple : Disco

    • Simple clic sur l'icône maison « aller au dossier personnel »

    • Retour aux dossiers personnels qui se trouvent sous l'utilisateur nommé : debian

  • Fermer le gestionnaire de fichiers : Simple clic > Fichier > Fermer la fenêtre

Pour plus de fonctionnalités : Simple clic > Aide > Guide d'utilisation > Lire en ligne
