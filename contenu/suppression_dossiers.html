Suppression d'un dossier ou d'un fichier : Le site Xfce.

Exemple : Suppression d'un dossier du nom de "vacances" qui se trouve dans le dossier Vidéos
Pour supprimer un fichier suivre la même procédure.

  • Ouvrir le gestionnaire de fichiers : Simple clic > Applications > Gestionnaire de fichiers

  • Le gestionnaire de fichiers Thunar s'ouvre.
    Ici, debian (nom utilisateur) doit être en bleu.

  • double clic > Vidéos

  • Pour supprimer le dossier "vacances" clic droit sur "vacances"
    Un menu déroulant s'ouvre.
    D'autres fonctionnalités sont disponibles comme : Copier, Coller, Renommer, etc.

  • Simple clic > Déplacer dans la corbeille

  • Le dossier "vacances" a été supprimé du dossier Vidéos.
    A ce stade, le dossier "vacances" n'a pas été supprimé totalement puisqu'il a été déplacé dans la corbeille.
  • Simple clic > Corbeille

  • le dossier vacances s'y trouve.
    Pour le supprimer : (a - vider la corbeille) ou (b - supprimer uniquement le dossier).
    a - Vider la corbeille : Clic droit > Corbeille

    b - Ou supprimer uniquement le dossier : Clic droit > vacances

  • Un menu déroulant apparaît.
    a - Vider la corbeille : Simple clic > Vider la corbeille

    b - Ou supprimer uniquement le dossier : simple clic > Supprimer

  • Une fenêtre de confirmation apparaît
    a - Vider la corbeille : Simple clic > Vider la cobeille

    b - Ou supprimer uniquement le dossier : simple clic > Supprimer

  • Le dossier vacances a été supprimé.
    Conseil : Vider la Corbeille de temps en temps.
  • Si la corbeille est vide
    Clic droit > Corbeille
    Un menu déroulant apparaît.
    Vider la corbeille est maintenant grisé.

  • Fermer le gestionnaie de fichiers : Simple clic > Fichier > Fermer la fenêtre

Nota : D'autres solutions existent pour supprimer un dossier ou un fichier mais la solution de le déplacer dans la corbeille permet de le retrouver en cas d'erreur.
Evidemment s'il a été supprimé de la corbeille, il est à ce moment-là supprimé définitivement.
