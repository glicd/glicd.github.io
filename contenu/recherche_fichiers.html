Rechercher un fichier ou un dossier : Le site Xfce.

Rechercher un dossier ou un fichier avec la fonction « Search ».

  • Exemple : Rechercher le dossier « vacances » sous le nom de l'utilisateur (debian)
    Sous Emplacements : Simple clic > debian (nom utilisateur)

  • Simple clic > l'icône de la loupe

  • « Search » doit apparaître dans le sélecteur d'emplacement.

  • A la suite de « Search » : Saisir, à l'aide du clavier, le nom du dossier ou du fichier recherché.
    Dans cet exemple le dossier recherché est « vacances »

  • Dans la zone principale apparaît le dossier ou le fichier recherché, ici le dossier « vacances »

  • Double clic > vacances, dans le sélecteur d'emplacement apparaît le chemin du dossier
    Le dossier « vacances » est dans le dossier « Vidéos » sous le nom de l'utilisateur (debian)

  • Fermer le gestionnaie de fichiers : Simple clic > Fichier > Fermer la fenêtre
