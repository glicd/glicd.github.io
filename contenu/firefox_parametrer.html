Paramétrer Firefox (changer le moteur de recherche) : Le site Mozilla Firefox

Le navigateur Firefox est installé par défaut sur Debian avec le bureau Xfce
La version installée est la version : Firefox ESR (Extended Support Release), plus d'information ici.

Qu'est ce qu'un navigateur web?

Avant de se rendre sur internet, il est préférable de configurer un pare-feu.
Si besoin, se rendre au chapitre : Les Applications > Le pare-feu avec l'interface utilisateur graphique gufw

  • Ouvrir le navigateur Firefox
    Simple clic > Applications > Internet > Firefox ESR

  • Le navigateur Firefox s'ouvre

  • Paramétrer Firefox :
    Exemple changer le moteur de recherche
    Simple clic sur le bouton > Ouvrir le menu de l'application

  • Le menu déroulant s'ouvre

  • Plusieurs fonctionnalités sont possibles comme par exemple :
    Ouvrir un nouvel onglet, imprimer une page web, paramétrer Firefox...
    Simple clic > Paramètres

  • L'onglet « Paramètres » s'ouvre

  • Dans le menu latéral de gauche plusieurs choix sont possibles :
    Général, Accueil, Recherche...
    Simple clic > Recherche

  • Le panneau de Recherche s'affiche

  • Dans cet exemple le moteur de recherche par défaut est « Qwant », pour le changer :
    Simple clic sur le bouton indiqué « Qwant »

  • Une liste déroulante apparaît.

  • Choisir le moteur de recherche souhaité
    Exemple : DuckDuckGo
    Simple clic > DuckDuckGo

  • Le moteur de recherche par défaut est maintenant : DuckDuckGo

  • Si besoin, pour configurer Firefox se rendre sur le site officiel :
    Simple clic > Assistance de Firefox

  • Quitter Firefox
    Simple clic > Petite croix

Site officiel : Options, préférences et paramètres de Firefox support.mozilla.org
