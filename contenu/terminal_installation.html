Configurer les sources de Apt (advanced package tool) en mode console en utilisant l'Emulateur de terminal : Debian

Configurer le fichier sources.list, qui se trouve dans : /etc/apt/sources.list

L'Emulateur de terminal :

L'Emulateur de terminal est une application qui fournit une interface utilisateur textuelle.
C'est ce que l'on appelle une interface en ligne de commande. C'est souvent le moyen le plus simple, le plus rapide et le plus puissant d'effectuer une certaines tâche.

Attention : L'Emulateur de terminal est à utiliser avec le plus grand soin.

AVANT de poursuivre, consulter SourcesList du wiki.debian

    1. Ouvrir l'Emulateur de terminal : Simple clic > Applications > Emulateur de terminal.

    2. Le Terminal s'ouvre en simple utilisateur puisqu'il y a le symbole « $ ».

    3. Pour se connecter au compte Root (superutilisateur) saisir : « su - » puis valider avec la touche Entrée du clavier.

    4. Saisir le mot de passe du "superutilisateur" Root, rien ne va apparaître à l'écran puis valider avec la touche Entrée du clavier.

    5. Si le croisillon « # » s'affiche, alors bienvenue dans le compte administrateur.

    6. Saisir : nano /etc/apt/sources.list puis valider avec la touche Entrée du clavier.

    7. Si l'installation de Debian a été faite via un support externe (exemple : clé usb) associé à une connexion internet :
      Le fichier sources.list doit ressembler à celui ci-dessous.

    8. Si les prochaines mises à jour s'effectuent par internet, il n'y a plus besoin de pointer sur le cdrom.
      AVANT de poursuivre, consulter SourcesList du wiki.debian
      Changement de http > https pour utiliser les dépots sur des connexions HTTPS chiffrées.
      Et, si souhaité, ajouter les composants "contrib non-free"

      9. Si souhaité, modifier :

      par :

      La ligne : deb cdrom : [ Debian GNU/Linux 12.2.0_ bookworm ...] peut être effacée.
      Ou ajouter le croisillon « # » ce qui veut dire que la commande concernant le cdrom ne sera plus prise en compte.

    9. Enregistrer avec les touches du clavier : Ctrl et la lettre « o » puis valider avec la touche Entrée du clavier

    10. Sortir avec les touches du clavier : Ctrl et la lettre « x »

    11. Retourner dans : nano /etc/apt/sources.list, les modifications ont été enregistrées.

    12. Sortir avec les touches du clavier : Ctrl et la lettre « x »

    13. Pour sortir du compte administrateur saisir : exit (valider avec la touche Entrée du clavier)

    14. On se retrouve sur le compte simple utilisateur puisqu'il y a le symbole « $ ».

    15. Pour consulter la documentation du Terminal : Simple clic > Aide > Guide d'utilisation

    16. Sortir du compte simple utilisateur à l'aide du clavier saisir : exit > valider avec la touche Entrée du clavier
