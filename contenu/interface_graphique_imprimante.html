L'interface graphique de configuration. Debian et Xfce

Comme indiqué dans le chapitre Imprimante seule l'interface graphique « system-config-printer » sera détaillée.
Le site ici

  • Ouvrir l'interface graphique : Simple clic > Applications > Paramètres > Configuration de l'impression

  • L'application de l'interface graphique s'ouvre.

      1. Barre de menus : Serveur, Imprimante... et le bouton « Déverrouiller » - « Verrouiller »
      2. Liste des imprimantes :
        • L'imprimante « MEMO » qui a été ajoutée.
      3. Barre d'état : Connectée à ...

  • Pour modifier les réglages des imprimantes, il faut déverrouiller la boite de dialogue.
    Simple clic > Déverrouiller

  • Une fenêtre apparaît, demandant le mot de passe pour Root (superutilisateur)

  • Saisir le mot de passe pour Root (superutilisateur) et valider avec la touche Entrée du clavier
    Ou simple clic > S'authentifier

  • Les modifications sont maintenant possibles puisque la boite de dialogue est déverrouillée.

  • Placer le pointeur de la souris sur l'imprimante « MEMO » > clic droit
    Une liste déroulante apparaît :
    • Propriétés : Faire des modifications, imprimer une page de test, etc.
    • Supprimer l'imprimante
    • Activer ou désactiver l'imprimante
    • Définir par défaut
    • Voir la file d'attente des impressions

  • Dans la liste déroulante :
    « Définir par défaut » est grisé. Cela veut dire que l'imprimante est définie par défaut.
    Le rond vert avec le V blanc sur l'icône de l'imprimante indique que l'imprimante est définie par défaut.

  • Quitter l'application graphique : Simple clic > Serveur > Quitter
