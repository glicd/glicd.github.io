Imprimante : Debian et Xfce

Le système principal d'impression est le Common UNIX Printing System (CUPS) Le site CUPS

CUPS est le service d'impression par défaut.
CUPS détecte automatiquement les imprimantes.

Il peut être configuré et contrôlé en utilisant une interface web ou une interface graphique.

  • Utiliser une interface web : CUPS est accessible via « http://localhost:631/admin ».
  • Utiliser une interface graphique : CUPS prend en charge une interface utilisateur graphique qui est
    « system-config-printer »

Pour fonctionner, certaines imprimantes multifonctions ont besoin de paquets supplémentaires :

  • Imprimante HP, ajouter, si besoin, le paquet : « hplip » et « hplip-gui » (utilitaires graphiques)
    Paquet/hplip
  • Imprimante Canon, ajouter, si besoin, le paquet : « cups-backend-bjnp »
    Paquet/cups-backend-bjnp
  • Imprimante Brother, ajouter, si besoin, le paquet : « printer-driver-brlaser »
    Paquer/printer-driver-brlaser
  • Imprimante Epson, ajouter, si besoin, le paquet : « printer-driver-escpr »
    Paquet/printer-driver-escpr
  • Et d'autres...

De plus, si besoin, se référer au site du constructeur de l'imprimante pour télécharger les pilotes Linux.

Dans ce mémo seule l'interface graphique « system-config-printer » sera détaillée.
